# Saved 2026 experiment outputs

Generated by `experiment2026.py`, five seeds 0–4. `metrics.csv` has 105 classification rows and `ood_metrics.csv` has 70 OOD rows. `summary.json` reports means and sample standard deviations. `predictions.npz` contains targets plus probabilities and logit variances, keyed by method, seed and condition. `models_seed0.pt` saves the seed 0 backbones, corrections and posteriors. Load this locally generated PyTorch file only from a trusted copy.

`setup_times.csv` excludes backbone training and inference. Full Jacobian extraction is shared across subset ablations and separately recorded, so fitting times are not total independently optimized subset times. `mc_convergence.csv` checks seed 0 full Rich-BLL predictions. `numeric_checks.json` checks clean full-Rich minus BLL variances. `split_indices.json` includes digit partitions, sampled clothing indices, and training-relative subset indices. `environment.json` records versions, settings and dataset checksum. Plots are generated by `plot_results2026.py`.
